# fufu.dev

Personal website for Jeremy Dai, built with Next.js, MDX, and Tailwind CSS.

## Development

```bash
make dev        # Run local dev server on http://localhost:3000
make typecheck  # TypeScript check (tsc --noEmit)
make lint       # ESLint check
make build      # Production build
```

Content schemas (bilingual blog posts and project frontmatter) and repository-specific design rules live in [`CLAUDE.md`](./CLAUDE.md).
