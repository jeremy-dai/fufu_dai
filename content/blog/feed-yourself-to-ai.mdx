上周末让 Claude 帮我排这周的时间。什么背景都没给。它说：你上周工作了四十五个小时，休息比例在降，考虑到马上要飞韩国，建议先把高优任务清了。

那种被看透的感觉，怎么说呢，还挺爽。哈哈哈。

## 从七年前说起

事情要从7年前说起。那时候开始记录自己每天每个小时在干什么，一开始纯粹是为了把生活游戏化。每天看到自己把时间花在哪，有种小任务完成的快感。像在给自己的一天打分。那时候没有 AI，数据全靠 Excel 公式汇总，搓一个看板出来，看着还挺有成就感。

后来 AI 来了。

## Markdown 是大模型的母语

我发现这些数据如果自动同步到笔记库里，变成 markdown 文件，AI 就能直接读懂。不需要数据库，不需要 API 对接。一行 `09:00-11:30 | W` 它就知道你上午工作了两个半小时。Markdown 对大模型来说就是母语。

于是我搭了个定时任务，每天自动把我的时间数据、财务数据、聊天内容，滴答清单的任务等等全同步进来。从那以后，我的笔记库里会躺着一批文件，每天自动更新，安安静静地等 AI 来读。我也会做轻量的维护，把散落的想法，查阅的资料等放进来。

随着数据的增多，AI越来越懂我。比如它前两天发现我任务列表里有些事一直没动，而晚上经常连续几个小时在做跟计划无关的事。它直接跟我说：你是兴趣驱动的人，所以需要更好地利用这一点。

## 一个数据中心，加上一堆前端

现在回头看，整个系统的逻辑其实挺简单：一个数据中心，加上一堆前端。数据中心就是笔记库，所有东西最终汇到这里。前端是各种工具——记时间的、记账的、管任务的。这些前端可以完全按自己的习惯来，因为可以是自己 vibe code 出来的。想要什么交互就做什么交互，想要游戏化就游戏化，想要一眼看出今天在干嘛的看板就做看板。不用迁就任何现成产品的逻辑。

然后所有跟 AI 的对话都从这个笔记库开始。它能读到我的时间记录、财务状况、任务清单、平时工作时的对话、读过的东西、写过的笔记。

## 被记住的感觉

跟它聊天经常会有那种时刻：它翻出你之前写过的某段想法，或者关联到你三个月前的一个观察，然后你觉得，哦，它真的记得。这种被记住的感觉，说实话，是我最喜欢这套系统的原因。不是效率提升，不是数据看板，是有一个东西持续地了解你。

目前最大的副作用是，有时候会想：了解一个人，也许真的不需要意识。
